# Kollekt

**Transformez vos clients occasionnels en clients réguliers.**

Kollekt est une solution SaaS de fidélité digitale moderne, simple et accessible, conçue pour les food trucks, restaurants indépendants, cafés et petits commerces locaux. 

La solution permet aux commerçants de créer une carte de fidélité personnalisée que leurs clients ajoutent directement à **Apple Wallet** ou **Google Wallet**, sans application mobile à télécharger.

---

## 🚀 Fonctionnalités principales

- **Sans application :** Fonctionne directement depuis le navigateur et les portefeuilles natifs du téléphone (Apple Wallet / Google Wallet).
- **Parcours commerçant rapide :** Création du compte, personnalisation de la carte (logo, couleurs, règles de points ou tampons) et génération du QR code d'inscription.
- **Scan au comptoir :** Interface fluide pour attribuer des points ou valider des récompenses en quelques secondes.
- **Sécurité et isolation :** Gestion des permissions par rôles (propriétaires et employés) et isolation des données par commerçant.

---

## 🛠️ Stack technique

- **Interface :** React / Next.js avec TypeScript & Tailwind CSS
- **Backend & Base de données :** Supabase (Auth, PostgreSQL, RLS)
- **Gestion des Pass Wallet :** Intégration WalletPasses
